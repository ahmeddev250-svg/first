# Cabinet ORL Rabat – Dr. Khaoula KARIM

Site web médical bilingue (Français / Arabe RTL) avec réservation de rendez-vous par créneaux fixes de 30 minutes et transmission directe via WhatsApp.

## Installation & Lancement

```bash
npm install
npm run dev
```

Pour exposer le serveur sur le réseau local (test mobile) :

```bash
npm run dev -- --host
```
